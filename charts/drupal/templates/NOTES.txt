By default, helm uninstall removes all chart-created resources, including the
VerticalPodAutoscalers, except retained PersistentVolumeClaims and chart-created
Secrets. A reinstall with the same
release name and namespace adopts retained PVCs and Secrets that still carry
this release's Helm ownership metadata. Existing Secret data is reused so that
persistent MariaDB and Redis data keep matching their credentials.

Passwords are not Helm values. Manage the external SMTP password only in:
  Secret {{ include "drupal.smtpSecretName" . }}, key SMTP_PASSWORD

After changing that Secret, restart the Drupal Deployment:
  oc -n {{ .Release.Namespace }} rollout restart deployment/{{ include "drupal.drupalName" . }}
